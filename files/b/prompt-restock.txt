請幫我在 n8n 做一個「家用品補貨提醒」流程。

需求：
1. 手動執行就好，不要排程。
2. 用一個 Edit Fields 節點放假資料：item（品名，文字）、qty（剩下數量，數字）、min（門檻，數字）。先放：衛生紙、2、3。
3. 用 IF 節點判斷：qty 小於 min 才往下走。
4. 最後用 Edit Fields 產生一行 draft：「<品名> 剩 <數量>，低於 <門檻>，記得補貨」。

限制：
- 總共 4 個節點，節點名稱用中文。
- 不要加通知、寄信、寫檔、HTTP Request，也不要用任何憑證。
- 不要 Publish（不要啟用）。
- 做完告訴我每個節點在做什麼。

我會自己測這四種情況：
- 正常：衛生紙 2、門檻 3 → 產生 1 行草稿
- 剛好等於：數量 3、門檻 3 → 不產生草稿
- 缺資料：沒有 qty → 看流程怎麼反應
- 打錯欄位：把 Expression 裡的 qty 打成 qyt → 看流程怎麼反應
