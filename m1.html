M1｜第一個流程

按一下就產生一則假的早報約 1 小時先修：M0實測 n8n 2.48.4（2026-11-18）・你的畫面可能略有不同

成果與先修

按一下手動執行，產生一則假的早報。 先完成 M0。已經會設定欄位與查看執行結果的人可以從驗收開始。 不用新帳號，主線費用 0 元。準備能開啟的本機 n8n 與本頁素材。

白話觀念

Trigger 是讓流程開始的觸發條件，本課用 Manual Trigger 手動啟動。Node 是做一件事的節點。Item 是一筆資料，裡面可有好幾個欄位。Execution 是流程執行一次的紀錄。Edit Fields (Set) 可以填入或整理欄位。Expression 是執行時取資料的寫法，{{ $json.欄位 }} 在本課用來拿上一個節點交來的欄位。數字欄位選 Number，文字欄位選 String。

手動 → 假資料（1 個 Item）→ 早報文字（1 個 Item）

素材包

  • main-start.json 已放好手動與假資料，供主線接著做。
  • main-done.json 是假早報完成版。
  • ex1-done.json 是午餐記帳完成版。
  • ex2-done.json 是學習提醒完成版。

使用 Import from File 讀入流程檔。位置見版本附頁。

主線：假早報

把假股價與假匯率組成一則標示測試的早報，金額只作紀錄與提醒。

節點 用途 關鍵設定
手動（Manual Trigger） 手動啟動 執行整條流程
假資料（Edit Fields (Set)） 提供測試欄位 stockName 假想甲（String）、stockClose 100（Number）、usd 32.85（Number）
早報文字（Edit Fields (Set)） 組合句子 report（String），值切換 Expression
起始版（m1/main-start.json）下載 .json（用 n8n 的 Import from File 匯入）
{

  "nodes": [
    {
      "name": "手動",
      "type": "n8n-nodes-base.manualTrigger",
      "typeVersion": 1,
      "position": [
        0,
        0
      ],
      "parameters": {}
    },
    {

      "typeVersion": 3.4,
      "position": [
        220,
        0
      ],
      "parameters": {
        "mode": "manual",
        "assignments": {
          "assignments": [
            {
              "id": "a1",
              "name": "stockName",
              "value": "假想甲",
              "type": "string"

  1. 匯入起始版，打開「假資料」，核對上表的值與型別，再執行流程。 你應該看到：「假資料」輸出 1 筆，三個欄位與上表一致。

  2. 接上 Edit Fields (Set)，命名為「早報文字」，用 Add Field 新增 report，型別選 String，值切換 Expression 後貼入下方句子。位置見版本附頁。

    【測試早報】{{ $json.stockName }}收盤 {{ $json.stockClose }} 元｜美元 {{ $json.usd ?? '未提供' }}

    你應該看到：預覽把欄位換成假想甲、100 與 32.85。

卡住了？預覽仍顯示大括號文字時先確認值已切換 Expression，並檢查欄位名稱大小寫。

  1. 按 Execute workflow 執行整條流程，打開「早報文字」查看輸出。位置見版本附頁。 你應該看到：report 為 【測試早報】假想甲收盤 100 元｜美元 32.85，共 1 筆。

  2. 刪除「假資料」中的 usd 欄位並重跑，再恢復 usd 為 32.85 重跑。 你應該看到：刪除時顯示 美元 未提供，恢復後顯示 美元 32.85。

?? '未提供' 會在該值缺少或為 null 時顯示提示。這樣可以保留「沒有匯率」的資訊。

小練習①：午餐記帳

自行建立三個節點，把午餐品項與金額寫成支出草稿。

節點 用途 關鍵設定
手動（Manual Trigger） 啟動流程 手動執行
午餐（Edit Fields (Set)） 記錄午餐 item 便當（String）、amount 95（Number）
支出草稿（Edit Fields (Set)） 組合文字 draft（String）

  1. 建立新流程，依表加入並連接節點，填好「午餐」的兩個欄位，執行一次。 你應該看到：「午餐」輸出 1 筆，item 為便當，amount 為數字 95。

  2. 將「支出草稿」的 draft 值切換 Expression，輸入下方內容，再執行整條流程。

    午餐：{{ $json.item }} {{ $json.amount }} 元

    你應該看到：draft 為 午餐：便當 95 元，共 1 筆。

卡住了？品項空白時先核對來源欄位是否叫 item，並檢查連線是否從「午餐」接入「支出草稿」。

小練習②：學習提醒

自行建立一則含姓名與讀書分鐘數的提醒。

節點 用途 關鍵設定
手動（Manual Trigger） 啟動提醒 手動執行
學習（Edit Fields (Set)） 提供提醒資料 who 阿禾（String）、minutes 20（Number）
提醒文字（Edit Fields (Set)） 組成提醒 text（String）

  1. 建立新流程，依表加入三個節點並連線，執行後檢查「學習」。 你應該看到：1 筆資料含 who 阿禾與數字 minutes 20。

  2. 將「提醒文字」的 text 值切換 Expression，輸入下方內容，再執行整條流程。 你應該看到：text 為 阿禾，今天讀書 20 分鐘。

{{ $json.who }}，今天讀書 {{ $json.minutes }} 分鐘

卡住了？分鐘數沒出現時先比對 minutes 的拼字與上游輸出，再重跑整條流程。

看懂執行紀錄

打開 Executions，選擇剛剛的執行時間。位置見版本附頁。 先看「假資料」輸出，再看「早報文字」輸入，確認兩邊同樣有 1 筆與三個欄位，最後比對 report 全句。 刪除 usd 的那次執行，來源應缺少該欄位，最後文字應顯示「未提供」。

故障驗收時打開失敗的「早報文字」，指出 report 的 Expression 引用出錯，記下錯誤訊息原文。修好後比對新的執行時間與輸出。

驗收

  • 正常。早報輸出 1 筆，report 為 【測試早報】假想甲收盤 100 元｜美元 32.85。
  • 缺資料。刪除 usd 後顯示 美元 未提供，沒有用 0 代填，恢復欄位後重跑成功。
  • 重複。相同假資料連跑兩次，每次輸出各 1 筆，找到兩次執行紀錄。
  • 故障。把 report 裡的美元取值暫改為 {{ $('不存在').item.json.usd }}，執行後指出「早報文字」的 report 引用失敗，再恢復原式並重跑。
  • 變形題。用三個節點製作旅費草稿，自訂外幣預算與欄位名稱，說明每個欄位如何進入最後文字。
卡關救援
  • 改設定後結果沒變 → 查看執行時間及來源資料是否被 Pin data 釘住，釘選會固定測試輸出 → 先解除釘選並重跑整條流程 → 比對新的執行時間與改過的值。位置見版本附頁。
  • 畫面出現大括號原文 → 查看文字欄位的值模式 → 先切換 Expression → 確認預覽與執行輸出都換成資料。
  • 取不到欄位 → 查看上一個節點的輸出與連線 → 先核對大小寫與拼字 → 確認輸入有該欄位、輸出有對應文字。
  • 引用節點失敗 → 查看失敗節點的錯誤與 report → 先恢復 $json.usd ?? '未提供' → 重跑後確認完整早報與 1 筆輸出。

求助時附 n8n 版本、預期與實際結果、哪個節點、錯誤訊息原文、已經試過什麼。截圖先遮住金鑰和個資。
